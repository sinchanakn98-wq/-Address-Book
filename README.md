A contact management application developed in C that allows users to add, search, edit, delete, and manage contact details using file handling.

# Address Book Management System in C

## Description
A contact management application developed using C programming.

## Features
- Add new contacts
- Search contacts
- Edit existing contacts
- Delete contacts
- Display all contacts
- Save and load contact details using file handling

## Technologies Used
- C Programming
- Structures
- Pointers
- Functions
- File Handling
- Strings

## How to Compile
gcc *.c -o addressbook

## How to Run
./addressbook
